# FastAPI Basics

A hands-on FastAPI course repository.

## Roadmap

01. First FastAPI App
02. Routing & Path Parameters
03. Query Parameters
04. Request Bodies
05. Pydantic Validation
06. Response Models & Status Codes
07. CRUD API (In-Memory)
08. Error Handling
09. API Documentation
10. Project Structure & APIRouter
11. SQLite Database
12. SQLAlchemy
13. Dependency Injection
14. Async FastAPI
15. Authentication
16. Testing
17. Configuration & Environment Variables
18. CORS
19. Final Project

`test01.py` is the original asyncio foundation exercise.

## Run an individual lesson

From the lesson directory:

```bash
uvicorn main:app --reload
```

For lesson 10 onward, use the command shown in that lesson's README.
