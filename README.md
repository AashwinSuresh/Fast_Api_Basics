## Running an Individual Lesson

Navigate into any lesson directory and run:

```bash
uvicorn main:app --reload
```

For lessons with custom layouts or scripts (such as `00-async-example`, `09-mini_project`, `10-routers-project-structure`, or `15-cors`), refer to the clear instructions inside that lesson's own `README.md`.
